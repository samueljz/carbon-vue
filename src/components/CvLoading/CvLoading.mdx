## Overview

Loading spinners are used when retrieving data or performing slow computations. They notify to the user that their request is being processed.

<Canvas of={LoadingStories.Default} />

Use the **Controls** panel to toggle between variants:
- **small**: Toggle to see the small loading spinner
- **overlay**: Toggle to add an overlay background
- **inactive**: Toggle to stop the spinner animation
