## Overview

Links are used as navigational elements and can be used on their own or inline
with text. They provide a lightweight option for navigation but like other
interactive elements, too many links will clutter a page and make it difficult
for users to identify their next steps. This is especially true for inline
links, which should be used sparingly.

## Accessible Link with Icon

If the text of your link doesn't correspond to the action represented by the
icon, consider incorporating an `aria-label` for the icon. This will ensure that
visually impaired users can comprehend the outcome of clicking the link.

## Component API

<ArgTypes of={LinkStories} />

### Link `href`

Provide the href attribute for the link element.

```vue
<CvLink href="https://www.carbondesignsystem.com">Carbon Design System</CvLink>
```

### Link `size`

Specify the size of the Link. Currently supports `sm`, `md` (default), or `lg`.

```vue
<CvLink size="sm">Small link</CvLink>
<CvLink size="md">Medium link</CvLink>
<CvLink size="lg">Large link</CvLink>
```

### Link `inline`

Specify whether the link should render inline with text.

```vue
<p>
  This is some text with an <CvLink inline href="#">inline link</CvLink> in it.
</p>
```

### Link with Icon

You can add an icon to the link using the `icon` slot.

```vue
<CvLink href="#">
  Link text
  <template #icon>
    <!-- Your icon SVG here -->
  </template>
</CvLink>
```
