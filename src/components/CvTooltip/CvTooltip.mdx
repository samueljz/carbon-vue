## Component API

<ArgTypes of={TooltipStories} />

### Tooltip `align`

Specify how the trigger should align with the tooltip. Options include:
- `top`, `top-start`, `top-end`
- `bottom`, `bottom-start`, `bottom-end`
- `left`, `left-start`, `left-end`
- `right`, `right-start`, `right-end`

```vue
<CvTooltip align="bottom-start">
  <button>Trigger</button>
  <template #content>
    <cds-tooltip-content>Tooltip content</cds-tooltip-content>
  </template>
</CvTooltip>
```

### Tooltip `enterDelay` and `leaveDelay`

Control the delay in milliseconds before showing or hiding the tooltip.

```vue
<CvTooltip :enter-delay="0" :leave-delay="300">
  <button>Trigger</button>
  <template #content>
    <cds-tooltip-content>Tooltip content</cds-tooltip-content>
  </template>
</CvTooltip>
```

### Tooltip Content

Use the `content` slot to provide the tooltip content. The content should be wrapped in a `cds-tooltip-content` element.

```vue
<CvTooltip>
  <button>Trigger element</button>
  <template #content>
    <cds-tooltip-content>Your tooltip text here</cds-tooltip-content>
  </template>
</CvTooltip>
```
