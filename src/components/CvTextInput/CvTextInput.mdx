## Overview

The `CvTextInput` component enables users to enter free-form text data. The
type of text field used should reflect the length of the content you expect the
user to enter. The default text input is for short, one-line content.

### CvTextInput Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `string` | `''` | The input value (v-model) |
| `label` | `string` | - | Specify the label text |
| `helperText` | `string` | - | Specify the helper text |
| `placeholder` | `string` | - | Specify the placeholder text |
| `disabled` | `boolean` | `false` | Whether the input is disabled |
| `readOnly` | `boolean` | `false` | Whether the input is read-only |
| `invalid` | `boolean` | `false` | Whether the input is invalid |
| `invalidText` | `string` | - | The invalid state message |
| `warn` | `boolean` | `false` | Whether to show a warning |
| `warnText` | `string` | - | The warning message |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Input size |
| `type` | `string` | `'text'` | Input type |
| `hideLabel` | `boolean` | `false` | Whether to hide the label |
| `enableCounter` | `boolean` | `false` | Whether to show character count |
| `maxLength` | `number` | - | Maximum character length |

### Events

| Event | Description |
|-------|-------------|
| `@update:modelValue` | Emitted when input value changes |
| `@input` | Native input event |
| `@change` | Native change event |
| `@blur` | Native blur event |
| `@focus` | Native focus event |

### Usage with v-model

```vue
<script setup>
import { ref } from 'vue';
import { CvTextInput } from '@carbon/vue';

const username = ref('');
</script>

<template>
  <CvTextInput
    v-model="username"
    label="Username"
    placeholder="Enter your username"
    helper-text="This will be visible to other users"
  />
</template>
```

### Validation Example

```vue
<script setup>
import { ref, computed } from 'vue';
import { CvTextInput } from '@carbon/vue';

const email = ref('');
const isInvalid = computed(() => {
  if (!email.value) return false;
  return !email.value.includes('@');
});
</script>

<template>
  <CvTextInput
    v-model="email"
    label="Email"
    :invalid="isInvalid"
    invalid-text="Please enter a valid email address"
  />
</template>
```
