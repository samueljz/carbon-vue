<ArgTypes of={ToggleStories} />

### CvToggle Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelValue` | `boolean` | `false` | The checked state (v-model) |
| `labelText` | `string` | - | The label text for the toggle |
| `labelA` | `string` | `'Off'` | Label for the unchecked state |
| `labelB` | `string` | `'On'` | Label for the checked state |
| `disabled` | `boolean` | `false` | Whether the toggle is disabled |
| `hideLabel` | `boolean` | `false` | Whether to hide the label |
| `name` | `string` | - | The toggle name attribute |
| `size` | `'sm' \| 'md'` | `'md'` | Toggle size |
| `readOnly` | `boolean` | `false` | Whether the toggle is read-only |

### Events

| Event | Description |
|-------|-------------|
| `@update:modelValue` | Emitted when toggle state changes |
| `@change` | Native change event |

### Usage with v-model

```vue
<script setup>
import { ref } from 'vue';
import { CvToggle } from '@carbon/vue';

const darkMode = ref(false);
</script>

<template>
  <CvToggle
    v-model="darkMode"
    label-text="Dark mode"
  />
  <p>Dark mode is {{ darkMode ? 'enabled' : 'disabled' }}</p>
</template>
```

### Custom Labels

```vue
<CvToggle
  v-model="isActive"
  label-text="Status"
  label-a="Inactive"
  label-b="Active"
/>
```

### Small Toggle

```vue
<CvToggle
  v-model="value"
  label-text="Small toggle"
  size="sm"
/>
```

### Hidden Label

When you need to hide the label visually but keep it accessible to screen readers:

```vue
<CvToggle
  v-model="value"
  label-text="Toggle (hidden label)"
  hide-label
/>
```
