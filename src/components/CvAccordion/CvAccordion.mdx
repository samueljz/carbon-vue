## Overview

The accordion component delivers large amounts of content in a small space
through progressive disclosure. The header title gives the user a high level
overview of the content allowing the user to decide which sections to read.

Accordions can make information processing and discovering more effective.
However, it does hide content from users and it's important to account for a
defined user need before using an accordion.

## Component API

<ArgTypes of={AccordionStories} />

### Accordion `alignment`

Use the `alignment` prop to change the position of the accordion heading title
and chevron. The default alignment is `end`.

```vue
<CvAccordion alignment="start">
  <CvAccordionItem title="Section 1">Content</CvAccordionItem>
</CvAccordion>
```

### Accordion `isFlush`

Use the `isFlush` prop to remove the horizontal padding from the accordion
content. This prop does not work with `alignment="start"`.

```vue
<CvAccordion isFlush>
  <CvAccordionItem title="Section 1">Content</CvAccordionItem>
</CvAccordion>
```

### Accordion `size`

Use the `size` prop to change the size of the accordion. Valid values are `sm`,
`md`, and `lg`. The default size is `md`.

```vue
<CvAccordion size="sm">
  <CvAccordionItem title="Section 1">Content</CvAccordionItem>
</CvAccordion>
```

### AccordionItem `open`

Use the `open` prop to control whether an accordion item is expanded. You can
use `v-model:open` for two-way binding.

```vue
<script setup>
import { ref } from 'vue';
const isOpen = ref(false);
</script>

<template>
  <CvAccordion>
    <CvAccordionItem v-model:open="isOpen" title="Section 1">
      Content
    </CvAccordionItem>
  </CvAccordion>
</template>
```

### AccordionItem `disabled`

Use the `disabled` prop to prevent an accordion item from being expanded. You
can also use the `disabled` prop on the `CvAccordion` to disable all items.

```vue
<CvAccordion>
  <CvAccordionItem title="Section 1" disabled>Content</CvAccordionItem>
</CvAccordion>
```
